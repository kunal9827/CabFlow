# CabFlow 🚖
**Corporate Cab Management System**

CabFlow is a web-based capstone project designed to manage corporate cab bookings. It includes different dashboards for Admins, Vendors, Drivers, and Employees.

### 🚧 Work in Progress
*Note: I am currently in the process of uploading the project files. Right now, the Login (`index.html`) and Admin Dashboard (`admin.html`) are uploaded. The remaining dashboards will be added in the next day or two!*

### 💻 Technologies Used
* **Frontend:** HTML, CSS, Vanilla JavaScript
* **Database:** LocalStorage (Will be migrated to MySQL/MongoDB)

### ✨ Features (Coming Soon)
* **Role-Based Login:** Different views for Admin, Vendor, Driver, and Employee.
* **Admin Panel:** Manage contracts and view overall statistics.
* **Vendor Panel:** Add and manage cab fleets.
* **Employee Panel:** Book cabs with a 9-hour advance business rule.
* **Driver Panel:** View assigned trips and update ride status.

### 🚀 How to Run the Project
1. Download or clone this repository.
2. Open the `index.html` file in any web browser (like Chrome or Edge).
3. Use the demo credentials provided on the login screen to test the different roles.
